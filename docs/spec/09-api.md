# 09 — API surface

All HTTP on one port (`LLMOBS_HTTP_ADDR`, default `0.0.0.0:8080`); OTLP/gRPC on `LLMOBS_GRPC_ADDR` (default `0.0.0.0:4317`); an OTLP/HTTP-only listener on `LLMOBS_OTLP_HTTP_ADDR` (default `0.0.0.0:4318`, serves only `/v1/traces`) for exporters configured with the standard OTel port.

| Prefix | Purpose | Auth |
|---|---|---|
| `/v1/traces` | OTLP/HTTP ingest | `sk` (ingest scope) |
| `/api/auth/*` | login, OAuth, invites, reset | none / cookie |
| `/api/v1/*` | REST API (UI + SDK + CLI) | cookie, PAT, or `sk` |
| `/api/public/*` | browser-safe endpoints | `pk` |
| `/mcp` | MCP server (streamable HTTP) | PAT |
| `/healthz`, `/readyz` | probes | none |
| `/` (everything else) | web UI (SPA fallback to `index.html`) | — |

OpenAPI 3.1 generated by `utoipa`, served at `/api/openapi.json`; the TS SDK REST client and the UI API client are generated from it (`openapi-typescript`).

## Conventions

- JSON, `snake_case`. IDs: UUIDv7 strings; trace/span IDs as lowercase hex.
- `{project}` path segment accepts a project UUID or slug (`org-slug/project-slug` URL-encoded), or `current` when authenticated with an `sk` key (the key's project).
- Lists: `?limit=` (default 50, max 1000) + `?cursor=`; response `{data: [...], next_cursor: string|null}`.
- Time range params: `from`, `to` (RFC 3339 or epoch ms).
- Errors: RFC 7807 `{type, title, status, detail, errors?: [{field, message}]}`.
- Idempotency: `Idempotency-Key` header honored on POSTs that create resources (24 h memory).
- Rate limit headers (`RateLimit-*`, IETF draft) on 429.

## SSE

`text/event-stream`, `event:` names `span`, `trace`, `resync`, `ping` (every 15 s). Data = JSON of the light columns. Auth by cookie (UI) or bearer. Max 100 concurrent streams per user.

## MCP server

Streamable HTTP transport at `/mcp` (and `llmobs mcp-stdio --url … --token …` for stdio-only clients). Auth: `Authorization: Bearer pat-…`. Tools (all read-only in MVP):

| Tool | Input | Output |
|---|---|---|
| `list_projects` | — | projects the user can read |
| `get_schema` | `project` | views, columns, types, descriptions |
| `query_sql` | `project, query, params?, limit≤1000` | rows (JSON) + truncated flag |
| `list_saved_views` | `project, kind?` | saved views and SQL queries visible to the user |
| `search_traces` | `project, view?, filter?, search?, from?, to?, limit≤100` | trace summaries (`view` = saved view name; explicit args override it) |
| `get_trace` | `project, trace_id, include_payloads=false, max_chars=20000` | span tree with optional truncated I/O |
| `get_span` | `project, trace_id, span_id, max_chars` | full span |

Implemented with the `rmcp` crate. Output sizes are capped (`max_chars`) to protect agent context windows.
