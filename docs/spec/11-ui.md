# 11 — Web UI

Vite + React + TypeScript, TanStack Router (file routes, typed search params) + TanStack Query + TanStack Table (virtualized with TanStack Virtual), shadcn/ui + Tailwind, ECharts for charts, CodeMirror 6 for SQL/DSL editors (with schema-driven autocomplete), Shiki-free JSON viewer (custom collapsible tree). API client: `openapi-typescript` types generated from `crates/server/openapi.json` (committed as `web/src/api/schema.gen.ts`, checked up to date) with `openapi-fetch` + `openapi-react-query` (D75). Lint/format with Biome, tests with Vitest + Testing Library (D74). In development (`pnpm dev`) and in tests, Mock Service Worker answers the API from `fixtures/api/` (D76); `pnpm dev:server` proxies `/api` and `/v1` to a running `llmobs` on port 8080 instead. Mocks are never part of the production build. Built output embedded in the binary with `memory-serve` (brotli/gzip precompressed, ETags, SPA fallback). Dark and light themes.

**State in the URL:** time range, filter expression, search, sort, selected trace/span are all search params, so every view is shareable and bookmarkable.

```

/:org/settings/{general,members,llm-connections,usage,models}

/:org/:project/traces/:traceId           trace view (also opens as side panel from the list)

/:org/:project/experiments · /experiments/:id · /experiments/compare?ids=
/:org/:project/evaluators · /online-rules · /online-rules/:id
/:org/:project/alerts · /alerts/:id
/:org/:project/settings/{general,api-keys,members,score-definitions,channels,data}   (data = retention + GDPR deletion)
/admin/{users,settings}                  instance admins
```

Command palette (⌘K): jump to project/page, paste a trace ID to open it.

**Saved views** (traces, spans, sessions, users lists): a "Views" dropdown — save, save as, rename, delete, share with project, set as my default / project default. Loading a view replaces the URL params; a "modified" dot appears when the current state differs from the loaded view.

## Pages

### Traces (list)

- Header: **saved views menu**, time-range picker (presets 15m/1h/24h/7d/30d + custom; "live" toggle), filter bar (visual chips ⇄ text DSL with autocomplete and inline errors), search box, columns menu, toggles "Show evaluation traces" / "Show experiment traces" (off by default).
- Table (virtualized, infinite scroll by cursor): status dot, start time, name, input preview, output preview, duration, tokens, cost, models, session, user, tags, scores (one column per score name present, toggleable), environment.
- Live mode: subscribes to `/traces/stream`; new rows slide in at the top with a highlight; paused automatically when the user scrolls.
- Row click → trace side panel (wide drawer); `Enter`/`↑↓` keyboard navigation.
- Bulk actions: add to dataset, delete (admins), export CSV.
- Empty state: onboarding snippets (OTel env vars, Python, TS, Vercel AI SDK) with the project's key prefix.

### Trace view

- **Left:** span tree (indentation + kind icon + name + duration + cost; error spans red; collapsible; search within tree) with a toggle to a **timeline** (waterfall with time axis, zoom/pan). Live: if the trace is recent, subscribes to `/traces/:id/stream` and inserts spans as they arrive.
- **Right (selected span):** header (kind, name, model, provider, duration, TTFT, tokens breakdown incl. cache/reasoning, cost, status) and tabs:
  - *Chat* (for `messages` format): system instructions collapsed, messages as bubbles, tool calls/results as cards, reasoning collapsed, images/audio/PDF rendered from `media://` refs, tool definitions in a drawer.
  - *Input / Output*: JSON tree / text / raw toggle; copy buttons; "truncated at ingest" badge when applicable.
  - *Attributes*: metadata, attributes, resource attributes, events (exceptions with stack traces), links.
  - *Scores*: existing scores (source, value, reason, author) + annotation form driven by score definitions.
- Trace header: name, total duration/cost/tokens, session (link), user (link), tags, environment, release, actions (add to dataset, run evaluator on this trace, copy link, delete).

### Sessions

List (start, last activity, trace count, user, cost, errors, scores) and detail: a **chat transcript** reconstructed from each trace's root input/output in order, each turn expandable into its trace; session-level scores and annotation.

### Users

End users list (traces, sessions, cost, last seen, errors) and per-user page (timeline of their sessions/traces, totals). GDPR action "Delete all data of this user" (admins) with confirmation.

### Dashboard

Fixed layout: KPI tiles (traces, error rate, p95 latency, cost, tokens) with comparison to the previous period; charts for traces & errors over time, latency percentiles, cost by model (stacked), tokens by type, TTFT, score averages over time; a "top models by cost" table. Global filter DSL + time range + group-by (model/environment/release) apply to all widgets. Clicking a chart point opens the trace list filtered to that bucket.

### SQL console

CodeMirror editor with schema-aware autocomplete, `⌘↵` to run, result grid (virtualized) with "chart" tab (auto line/bar from first time/numeric columns), export (CSV/Parquet/NDJSON), example queries menu, **saved queries** (private or shared, with parameters), query history (localStorage). Schema browser on the side. Errors shown inline with position. The console has the shared time range picker, and every run and export sends its range as `from`/`to` (D101). The range is part of the URL state and of a saved query's run, like the other views.

### Datasets

List; dataset page with version selector, items grid (inline JSON editing in a side panel), add item, import wizard (upload → preview → column mapping → validate → import), export, version history with descriptions, and per-item "source trace" link.

### Experiments

List grouped by dataset; experiment page (aggregates header + items table with scores/latency/cost/output, filters "failed only", "regressions"), compare view (2–4 experiments: aggregate deltas as colored badges, per-item rows side by side with diffs of outputs). Code snippet to run a new experiment.

### Evaluators & online rules

- Evaluators: list; editor with template picker, prompt editor (variables highlighted), output type config, model/connection select, **test panel** (pick a trace/span or paste variables → run → shows score, reason, tokens, cost).
- Online rules: list with status (active / paused: budget / paused: errors), sample rate, spend vs budget; rule editor (evaluator, target, filter DSL with live "N matching in the last 24 h" counter, variable mapping with JSONPath preview on a sample trace, sampling, budget); rule page with recent jobs, failures, score distribution; "backfill" dialog with cost estimate.

### Alerts

Rules list with state badges; editor (metric, filter, window, threshold, min count, cooldown, channels) with a preview chart of the metric over the last 24 h and the threshold line; event history; channels management with "send test".

### Settings

Project: name, retention (days, with a warning about immediate partition drops), API keys (create with scopes/expiry, shown once, revoke), members/overrides, score definitions, channels, **Data** tab: GDPR deletions (by user ID, by filter with a preview count; deletion history and status), delete project. Org: members & invites (copyable invite link when SMTP is off), LLM connections (test button), custom model prices, usage (daily spans/bytes/judge cost charts), delete org.

## Quality bar

- Trace list first paint < 1 s on 1B spans (server targets in D23); trace view usable with 10 000 spans (virtualized tree).
- Keyboard: `/` focus search, `j/k` move in lists, `esc` close panel, `?` shortcuts help.
- Accessibility: shadcn/Radix primitives, focus management in drawers, color not the only status signal.
- No external network calls from the UI (fonts and icons bundled), so air-gapped installs work.
