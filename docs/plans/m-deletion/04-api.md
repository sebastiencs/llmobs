# M4 — Project deletion API

Read [README.md](README.md) first, especially § Design › Kinds, Access and Limits.

**Goal:** the project-scoped deletion routes, their types, their OpenAPI operations and their example responses:
- `POST /api/v1/projects/{project}/deletions` creates a `trace_ids`, `filter` or `user` deletion and answers `202`;
- `POST /api/v1/projects/{project}/deletions/preview` counts the traces a filter deletion would cover;
- `GET /api/v1/projects/{project}/deletions` lists the project's deletions, newest first;
- `GET /api/v1/projects/{project}/deletions/{id}` reads one.

M3's worker does the rest.

## Types

`crates/server/src/api/deletions.rs` (`pub` items, like the other `api` modules, since `llmobs_server::api` is public and the example tests use it):

```rust
//! Deletion request and response types (spec 09 § Pricing & GDPR, D-M-2).

use llmobs_core::ids::{OrgId, ProjectId};
use llmobs_core::time_serde;
use serde::{Deserialize, Serialize};
use utoipa::ToSchema;
use uuid::Uuid;

use super::common::TimeParam;
use super::keys::optional_time;

/// What a deletion covers.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
#[serde(rename_all = "snake_case")]
pub enum DeletionKind {
    /// Listed traces.
    TraceIds,
    /// Traces matching a filter, search and window.
    Filter,
    /// One end user's data.
    User,
    /// A whole project.
    Project,
    /// A whole organization.
    Org,
}

/// Where a deletion is (D-M-3).
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
#[serde(rename_all = "snake_case")]
pub enum DeletionStatus {
    /// Finding the traces it covers. The data is still visible.
    Resolving,
    /// Hidden from every read; bytes are erased within 24 h.
    Pending,
    /// Erased.
    Applied,
    /// Nothing was deleted; see `error`.
    Failed,
}

/// Why a deletion failed.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
#[serde(rename_all = "snake_case")]
pub enum DeletionFailure {
    /// The filter matched more than 100,000 traces when it was resolved.
    TooManyTraces,
    /// Finding the traces failed.
    ResolutionFailed,
}

/// Who requested a deletion.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
#[serde(rename_all = "snake_case")]
pub enum DeletionActorKind {
    /// A user, through a session or a personal access token.
    User,
    /// A project API key.
    ApiKey,
}

/// The requester.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
pub struct DeletionActor {
    /// `user` or `api_key`.
    pub kind: DeletionActorKind,
    /// The user id or the API key id.
    pub id: Uuid,
}

/// The selection of a `filter` deletion, as requested.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
pub struct DeletionFilter {
    /// Filter DSL text. Omitted when none was given.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub filter: Option<String>,
    /// Full-text search. Omitted when none was given.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub search: Option<String>,
    /// Window start, inclusive.
    #[serde(with = "time_serde")]
    #[schema(value_type = String, format = DateTime)]
    pub from: i64,
    /// Window end, exclusive.
    #[serde(with = "time_serde")]
    #[schema(value_type = String, format = DateTime)]
    pub to: i64,
    /// Evaluation traces were included.
    pub include_eval: bool,
    /// Experiment traces were included.
    pub include_experiments: bool,
}

/// A deletion request and its progress.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
pub struct Deletion {
    /// Deletion id.
    pub id: Uuid,
    pub kind: DeletionKind,
    pub status: DeletionStatus,
    /// The organization.
    pub org_id: OrgId,
    /// The project. Omitted for `org`.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub project_id: Option<ProjectId>,
    /// The end user (`user` only).
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub user_id: Option<String>,
    /// Distinct trace ids in the request (`trace_ids` only).
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub requested_traces: Option<u32>,
    /// The selection (`filter` only).
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub filter: Option<DeletionFilter>,
    /// Name of the dropped project or organization (`project`, `org`).
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub name: Option<String>,
    /// Slug of the dropped project or organization (`project`, `org`).
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub slug: Option<String>,
    /// Traces covered, including evaluation traces. Omitted until resolved.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub trace_count: Option<u64>,
    /// Sessions covered (`user`). Omitted until resolved.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub session_count: Option<u64>,
    pub requested_by: DeletionActor,
    /// When it was requested; rows ingested later are not deleted. JSON is RFC 3339.
    #[serde(with = "time_serde")]
    #[schema(value_type = String, format = DateTime)]
    pub created_at: i64,
    /// When storage began hiding the rows. Omitted before.
    #[serde(default, skip_serializing_if = "Option::is_none", with = "optional_time")]
    #[schema(value_type = Option<String>, format = DateTime)]
    pub handed_over_at: Option<i64>,
    /// When it was applied. Omitted before.
    #[serde(default, skip_serializing_if = "Option::is_none", with = "optional_time")]
    #[schema(value_type = Option<String>, format = DateTime)]
    pub applied_at: Option<i64>,
    /// Why it failed (`failed` only).
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub error: Option<DeletionFailure>,
}

/// `POST /api/v1/projects/{project}/deletions`.
#[derive(Debug, Clone, PartialEq, Eq, Deserialize, ToSchema)]
#[serde(tag = "kind", rename_all = "snake_case", deny_unknown_fields)]
pub enum CreateDeletion {
    /// 1 to 1,000 trace ids, 32 hex digits each, either case.
    TraceIds {
        trace_ids: Vec<String>,
    },
    /// Traces the trace list shows for this filter, search and window (at most 100,000).
    Filter {
        #[serde(default)]
        filter: Option<String>,
        #[serde(default)]
        search: Option<String>,
        from: TimeParam,
        to: TimeParam,
        #[serde(default)]
        include_eval: bool,
        #[serde(default)]
        include_experiments: bool,
    },
    /// Every span and score of one end user, with their traces and sessions.
    User {
        /// 1 to 255 bytes, matched exactly.
        user_id: String,
    },
}

/// `POST /api/v1/projects/{project}/deletions/preview`.
#[derive(Debug, Clone, PartialEq, Eq, Deserialize, ToSchema)]
#[serde(deny_unknown_fields)]
pub struct DeletionPreviewRequest {
    #[serde(default)]
    pub filter: Option<String>,
    #[serde(default)]
    pub search: Option<String>,
    pub from: TimeParam,
    pub to: TimeParam,
    #[serde(default)]
    pub include_eval: bool,
    #[serde(default)]
    pub include_experiments: bool,
}

/// How many traces a filter deletion would cover.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
pub struct DeletionPreview {
    /// Matching traces, at most 100,000.
    pub matched_traces: u64,
    /// More than 100,000 traces match: the deletion would be refused.
    pub capped: bool,
}
```

### `create_deletion`

```rust
async fn create_deletion(
    State(state): State<AppState>,
    Extension(principal): Extension<Principal>,
    Extension(access): Extension<ProjectAccess>,
    error::Json(body): error::Json<CreateDeletion>,
) -> Result<(StatusCode, error::Json<Deletion>), ApiError>
```

1. **Key limits.** `if matches!(principal, Principal::ApiKey { .. }) && !matches!(body, CreateDeletion::TraceIds { .. })` → `Err(ApiError::Forbidden { code: ProblemCode::Forbidden })`.
2. **Actor.**
   - `Principal::Session { user, .. }` and `Principal::Pat { user, .. }` → `(ActorKind::User, user.id)`;
   - `Principal::ApiKey { key_id, .. }` → `(ActorKind::ApiKey, key_id)`.
3. **Validate**, per kind, building the `NewDeletion` fields:
   - `TraceIds { trace_ids }`:
     - parse each with `TraceId::from_str`, collecting into a `BTreeSet<TraceId>`, then `let ids: Vec<TraceId> = set.into_iter().collect();`. Any failure is `field_error("trace_ids", "each trace id must be 32 hex digits, not all zero")`;
     - then `1..=MAX_TRACE_IDS` distinct ids, else `field_error("trace_ids", "send 1 to 1000 trace ids")`. Check the raw `trace_ids.len() > MAX_TRACE_IDS` first, before parsing, with the same error;
     - `request = RequestDetails { requested: Some(n as u32), ..Default::default() }`, with `u32::try_from(n)`. It fits under 1,000.
   - `Filter { filter, search, from, to, include_eval, include_experiments }`:
     - `let window = TimeWindow::new(from.ns(), to.ns())?;`. The `RunError` becomes `400 bad_request` through `From<RunError>`;
     - `filter` and `search` are kept only when they hold a non-whitespace character: `.filter(|text| !text.trim().is_empty())`. The stored text is not trimmed;
     - count: `let ctx = crate::routes::read::open_query(&state, access.project.id, None).await?;`, then `let ids = llmobs_storage::filter_trace_ids(&ctx, FilterDeletionRequest { filter: filter.as_deref(), search: search.as_deref(), window, include_eval, include_experiments, limit: state.deletions.filter_cap() + 1, timeout: READ_TIMEOUT }).await?;` (with `filter`/`search` already reduced to non-blank text). An invalid filter is `400 invalid_filter`, a timeout `422 query_timeout`, busy `503`. If `ids.len() > state.deletions.filter_cap()` → `Err(ApiError::TooManyTraces)`;
     - `request` sets `filter`, `search`, `from: Some(from.ns())`, `to: Some(to.ns())`, `include_eval: Some(include_eval)`, `include_experiments: Some(include_experiments)`.
   - `User { user_id }`: `1..=MAX_USER_ID_BYTES` bytes (`user_id.len()`), else `field_error("user_id", "user_id must be 1 to 255 bytes")`. `request` is the default.
4. `let id = Uuid::now_v7(); let now = state.clock.now_ns();`. `store::NewDeletion { id, org_id: access.project.org_id, project_id: Some(access.project.id), kind, user_id /* Some for User only */, request, actor_kind, actor_id, state: store::DeletionState::Resolving, created_at: now }`.
5. One `state.meta.write(move |conn| Box::pin(async move { … }))` returning `Result<store::DeletionRow, MetaError>`; move clones of `new` and `ids` into it:
   - `if count_open_in_project(conn, project).await? >= MAX_OPEN { return Err(MetaError::Conflict("too many open deletions")) }`;
   - `insert_deletion`;
   - for `TraceIds`, `insert_traces(conn, id, &ids)`.

   The conflict becomes `409 conflict`.
6. **Guard**, after the commit:
   - `TraceIds`: `state.deletions.guard.add_traces(project, &ids, now)`;
   - `User`: `state.deletions.guard.add_user(project, &user_id, now)`.
7. `state.deletions.wake.notify_one();`
8. Audit: `tracing::info!(target: "audit", deletion_id = %id, kind = kind.as_str(), org_id = %org, project_id = %project, actor_kind = actor_kind.as_str(), actor_id = %actor_id, "deletion requested");`.
9. `Ok((StatusCode::ACCEPTED, error::Json(deletion_json(&row))))`.

### `preview_deletion`

`State`, `Extension<Principal>`, `Extension<ProjectAccess>`, `error::Json<DeletionPreviewRequest>` → `Result<error::Json<DeletionPreview>, ApiError>`.
- A key is `403`.
- The window, the blank-text rule and the count are as in create.
- The answer is `DeletionPreview { matched_traces: min(len, cap) as u64, capped: len > cap }`. Over the cap is **not** an error here.

### `list_deletions`

`error::Query<PageParams>`.
- `after = params.cursor.as_deref().map(decode_time_cursor).transpose()?`.
- `let limit = params.limit.get();` (`u32`, 1–1000, so `limit + 1` cannot overflow). `rows = page_of_project(reader, project, after, limit + 1)`. If there are more than `limit` rows, truncate to `limit` and set `next_cursor = encode_time_cursor(last.created_at, &last.id.to_string())`.
- The answer is `Page { data: rows.iter().map(deletion_json).collect(), next_cursor }`.

### `get_deletion`

`error::Path<DeletionPath>` with `#[derive(Deserialize)] struct DeletionPath { id: Uuid }`. Check how `routes/api_keys.rs` extracts `{id}` and do the same. `deletion_in_project(reader, project, id)`; `None` → `ApiError::NotFound`.

### Mapping

`pub(crate) fn deletion_json(row: &store::DeletionRow) -> Deletion` in `routes/deletions.rs`. M5 reuses it. It uses four private one-to-one `match` functions: `kind_json(store::DeletionKind) -> DeletionKind`, `status_json(store::DeletionState) -> DeletionStatus`, `failure_json(store::FailReason) -> DeletionFailure`, `actor_kind_json(store::ActorKind) -> DeletionActorKind`. `org_id`/`project_id` pass through (same id types), `requested_by.id` is `row.actor_id`.
- `filter`: `Some(DeletionFilter { … })` only for `Filter`, from `row.request`. `from`/`to` are `unwrap_or(0)`, `include_*` are `unwrap_or(false)`. M4 always stores them.
- `requested_traces`: `row.request.requested`.
- `name`/`slug`: `row.request.name`/`slug`.
